WARSTWY CZASU — GENERATOR ANIMACJI

INSTALACJA PODSTRONY GENERATORA
1. Rozpakuj ten folder.
2. Wgraj folder „animacja” do głównego katalogu repozytorium XOOGKlastry/satelita.
3. Po publikacji przez GitHub Pages otwórz:
   https://xoogklastry.github.io/satelita/animacja/

UŻYCIE
1. Wybierz ZIP pobrany z aplikacji Warstwy Czasu.
2. Kliknij „Utwórz animację”.
3. Pobierz GIF albo samodzielną podstronę HTML.
4. Aby opublikować wynik jako kolejną stronę, utwórz folder w repozytorium,
   zapisz pobrany plik HTML jako index.html i zatwierdź zmianę.

ZIP jest odczytywany w przeglądarce. Zdjęcia nie są przesyłane na serwer.
Generator pobiera JSZip i gif.js z jsDelivr, więc do jego działania potrzebny
jest dostęp do internetu.

Repozytorium GitHub Pages jest statyczne. Generator nie zapisuje plików w
repozytorium automatycznie; tworzy gotowy plik HTML do pobrania i publikacji.
